THEALIST / PRODUCT NOTES

Project Documentation

System Flow & Logic ของ Thealist: interactive prototype บนหน้าเดียว ใช้ mock data เท่านั้น ไม่มีระบบจองหรือชำระเงินจริง

01 / การนำทางและการค้นหา

Top Navigation สลับ Home, Movies, News และ My Tickets ด้วย client-side state Movies มีแท็บ ค้นหา และตัวกรองประเภท News มีค้นหาและหมวดหมู่

02 / โครงสร้างหน้าจอ

MovieCard และ Movie Detail แสดงข้อมูลภาพยนตร์ตัวอย่าง TicketCard และ TicketDetails แสดงตั๋วจำลองพร้อม DEMO QR ที่ใช้เข้างานไม่ได้

03 / Demo booking flow

Book Tickets ทดลองเลือกเวลาและจำนวนบัตรเท่านั้น My Tickets ใช้ Demo Sign In และการยกเลิกใน client-side state ไม่มีการกันที่นั่ง ออกบัตร ชำระเงิน หรือคืนเงินจริง

04 / ข้อมูลและความเป็นส่วนตัว

ข้อมูลภาพยนตร์ ข่าว และการจองเป็น mock data ใน JavaScript ไม่มีการเรียก API แสดงเฉพาะการจองของ demo user ที่เข้าสู่ระบบ ไม่มีการรับรหัสผ่านหรือข้อมูลการชำระเงิน
